# walks numba backwards looking for a version that accepts an older numpy,
# lands on numba 0.53 from 2021, and tries to compile llvmlite 0.36 from source
# because no wheel exists for any current Python. The floors keep it on
# versions that ship wheels.

# absence and disables the endpoint cleanly. That build is about 310 MB.
